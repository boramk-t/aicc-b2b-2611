기능 배치 기준

  • 지식글 코멘트 관리는 지식 관리와 같은 메뉴입니다. 지식글 수정 요청 코멘트 처리는 KMS에서 하므로 지식 관리에서 KMS 팝업으로 넘깁니다. AI 추천 답변 좋아요/싫어요 피드백은 지식 관리에서 처리합니다.
  • 코칭 요청과 실시간 코칭은 상담 어드바이저 · 리더 어드바이저에서 쪽지(팝업 창) 주고받기로 보여 주고, 이력은 알림에 쌓습니다. 코칭 요청 하단에 첨부 파일 영역을 둡니다.
  • STT 단어사전 관리는 별도 STT 관리 메뉴에서 관리합니다(어드바이저 제외).
  • 상품명 관리는 키워드 관리의 하위 탭입니다.
  • 분석 기준 · 이력 관리는 BE 기능이라 화면에서 제외합니다.
  • 권한 위임은 리더 어드바이저 설정에서 합니다.
  • 상담사 VOC 추천 · 검색 · 등록 · 수정은 상담 어드바이저 메뉴에서 지원합니다.
  • 화면 레이아웃 · 글자 크기는 상담 어드바이저 메뉴(화면 설정)에, 자동 추천 설정은 상담 어시스트 설정에 포함합니다.
  • 복사 버튼은 복사 아이콘으로 표시합니다.
  • 리더 어드바이저에는 상담직원 상태 · 콜타임 지연 · 멀티뷰 · 실시간 대화 · 콜 청취 · 코칭 요청을, 실시간 모니터링에는 상담 운영 현황 · 통화 발생 빈도를 둡니다.
  • 멀티뷰는 리더 어드바이저 상담직원 목록에서 [대화 보기]를 누를 때마다 상담직원별 실시간 대화 팝업 창이 자동으로 열리는 방식입니다. 여러 명을 누르면 창이 여러 개 열립니다.
  • 상담 어시스트 책갈피는 상담어드바이저와 리더어드바이저가 같은 화면입니다.
  • 운영 관리 메뉴는 리더에게도 관리자와 같게 표시합니다.
  • 실시간 대화의 NER 태그를 누르면 그 값이 메모에 기록됩니다.

오안내 표시 규칙 (와이어프레임 오안내 1-1 ~ 1-8)

· 지식 추천 이후 상담직원 발화가 추천 지식과 다르면 실시간 대화에 [오안내 유의] 배지·"바른 답변을 확인하세요"·빨간 말풍선을 띄우고, 상담 어시스트 목록 맨 아래에 오안내 유의 카드를 추가합니다.
· 판정이 늦어져도 완료 즉시 표시합니다. 판정 중이거나 판정에 실패하면 아무것도 표시하지 않습니다. 통화당 감지 건수는 제한하지 않습니다.
· 표시하지 않는 발화: 지식 추천 이전 발화, 추천 지식과 일치하는 발화, 추천 지식과 맥락이 무관한 발화, 고객 발화.
· 한 발화에 오안내가 여러 건이면 말풍선 표시는 1개, 카드는 오안내마다 1개씩 만듭니다. 같은 오안내를 반복하면 매번 표시합니다.
· NER(개체명): 유형 라벨(DS Badge Weak) + 밑줄 값으로 표시하고, 값을 누르면 그 값이 메모에 기록됩니다(개인정보는 마스킹 값).

· 카드의 발화 시각을 누르면 실시간 대화가 해당 발화로, 출처를 누르면 근거 지식 위치로 이동합니다. 위로 스크롤한 상태에서 새 카드가 생기면 위치를 유지하고 새 카드 알림 버튼을 띄웁니다.

기능 설명 (넘버링 상세 기능 설명 기준)

Risk Call 및 위험 감지 알람실시간 대화 모니터링

고객이 민원성 불만 제기, 개인정보 유출 등 중요한 이슈나 사전에 등록한 위험상황 발생 시 상담직원과 리더에게 실시간 알람 제공

특정 인입번호 알림실시간 대화

특정 인입번호가 인입되면 상담직원과 리더에게 별도 알림을 주는 기능

고객정보탭 고정실시간 대화

실시간 대화 기록을 고정해야 할 때, 고객정보탭이 사라지지 않도록 고정하는 기능

STT 피드백 및 보정실시간 대화

STT 인식 결과 평가 및 오류 발생 시 보정

대화 내용 검색실시간 대화

텍스트로 변환된 대화 내용 중 특정 키워드를 검색하여 찾는 기능

통화상태 확인 및 알림실시간 대화

통화상태에 따라 [대기중], [통화중]을 화면에 출력하고 현재 통화 상태를 알림

고객 기본정보 조회 및 출력실시간 대화

통화가 연결된 현재/이전 고객의 정보 및 대화 기록을 조회하여 화면에 출력

실시간 대화 기록 (STT)실시간 대화

고객과 상담직원의 음성 통화 내용을 실시간으로 화자 분리하여 텍스트로 변환 및 출력

핵심 개체명 인식 (NER 태그)실시간 대화

실시간 대화 내용 중 NER(개체명)을 분석하여 핵심 키워드 정보를 태그 형태로 표시

통화 연결/종료 및 이동 버튼실시간 대화

통화 연결/종료 알림 및 스크롤뷰 최적화를 위한 화면 이동(하단 이동) 버튼 제공

고객 상담 이력 조회실시간 대화

고객의 과거 상담 이력, 상담 정보, STT 원문, 인입 채널(전환 정보 등) 상세 조회

오안내 알람 및 바른답변 정정 기능실시간 대화

상담직원이 오안내 했을 경우 알람 표시 및 바른답변으로 표출

발화의도분석실시간 대화

고객의 통화 발화 중 식별된 의도가 있다면 화면에 실시간으로 출력하는 기능

키워드(NER) 자동 메모 기록메모 기능

실시간 대화 기록에 있는 'NER 태그'를 클릭하면 해당 정보값이 자동으로 메모란에 기록되는 기능

일반 메모 작성 및 그룹핑메모 기능
