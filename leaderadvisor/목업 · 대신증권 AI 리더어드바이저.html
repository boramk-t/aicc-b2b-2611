· 상담직원 현황은 선택한 팀의 총원과 상태 카드 4개(통화중 · 대기중 · 자리비움 · 후처리)로 보여 줍니다. 통화중 카드에는 IB · OB 인원을 나눠 보여 줍니다.
· [팀 변경]을 누르면 팀 목록 팝오버가 열립니다. 전체 팀 또는 팀을 고르면 현황 카드와 상담직원 목록이 바뀝니다.
· 상담직원 목록은 이름 · 상태 · 알림 · 시간 4열이며 열마다 정렬합니다. 상태는 IB · OB(통화중) · 대기중 · 자리비움 · 후처리 배지, 알림은 감지된 리스크 인텐트 이름 배지(예: 개인정보유출 · 대외민원 · 손실보상요구)이고, 금지키워드 배지는 두지 않습니다. 리스크 인텐트는 도구 › 리스크 감지 설정에서 관리합니다. 시간은 지연콜 기준을 넘으면 중콜은 주황, 장콜은 빨강으로 표시하고, 자리비움 상담직원은 이름을 회색으로 표시합니다.
· 리더 어드바이저 화면에는 알림 토스트를 띄우지 않습니다. 코칭 요청은 LNB [알림]에서 확인하고, 문의 접수(Risk Call) · 관심 번호 통화 연결은 상담직원 목록의 알림 배지와 실시간 대화 창 안 안내로 봅니다.
· 상담직원 이름을 누르면 실시간 대화 창(새 창)이 열립니다. 여러 명을 누르면 상담직원별로 창이 하나씩 더 열려 동시에 모니터링합니다(멀티뷰). 창이 열린 상담직원은 목록에서 선택 상태로 표시합니다.
· 대화 창 위쪽에는 팀 · 고객 · 상담 유형(상담코드 대분류), 콜 청취, 통화 시간(지연콜 색)이 있고, 그 아래 줄에 상담직원 이름 · IB/OB · 알림 배지와 오른쪽 끝 대화 검색(돋보기)이 있습니다. 돋보기를 누르면 그 줄이 검색창으로 바뀌고 돋보기는 사라집니다. 검색창의 []를 누르면 원래 줄로 돌아옵니다. 대화 영역은 상담어드바이저 실시간 대화와 같습니다(통화 연결 안내 · 관심 번호 안내 · 고객 이력 정보 · NER 태그 · 말풍선 · 시간 표기).
· 대화 창 아래 코칭 메시지에서 상담직원이 보낸 요청 메시지 · 첨부 파일을 보고 코칭을 써서 보냅니다(파일 첨부 가능). 보낸 코칭은 상담직원의 실시간 대화에 코칭 말풍선으로 나타나고, 이력은 양쪽 알림에 쌓입니다. [추가 요청]은 상담직원 화면에만 있고, 리더 화면의 코칭 말풍선에는 두지 않습니다.

사용자 관리 동작 (PRD-사용자 관리)

· LNB [운영 관리] → 오른쪽 메뉴에서 [사용자 관리]를 고르면 목록이 열립니다. 처음에는 표 머리글과 빈 행만 보이고, 조회 조건을 정해 [검색]을 누르면 결과가 나옵니다. [초기화]는 조회 조건을 기본값으로 되돌립니다. 결과가 없으면 '검색 결과가 없습니다. 검색 조건을 변경해 주세요.'를 보여 줍니다.
· 목록은 체크박스 · 이름 · 사내 시스템 ID · 소속(센터 > 그룹 > 팀) · 직책명 · 역할 · 상태(서비스 이용 상태 활성/비활성 Badge) · 상태 기준 · 기한입니다. 기한은 사내 사용자 정보 기준이면 '자동 연장', 수동이면 수동 상태 종료일(날짜만, 예: 2026.11.30)입니다. 행을 누르면 사용자 상세로 이동합니다. 행을 1개 이상 선택하면 목록 아래 가운데에 플로팅 바(n명 선택 · [수동 상태 해제] · [] 선택 해제)가 뜹니다. 수동 상태 해제는 목록에서만 합니다. 목록 아래 [페이지당 표시]에서 한 화면에 보여 줄 개수를 10 · 20 · 30 · 40 · 50개 중에서 고릅니다(기본 10개 · 모든 목록 공통).
· [사용자 추가]는 Dialog(모달)입니다. [조직] 탭은 센터 > 그룹 > 팀 트리에서 고릅니다. 상위 조직을 고르면 하위 조직이 모두 선택됩니다. 하위 조직 하나를 해제하면 남은 하위 조직 단위로 선택이 바뀝니다. 팀이 없는 센터 · 그룹은 선택할 수 없습니다.
· [개인] 탭은 이름 또는 사내 시스템 ID로 검색하고, 결과는 '이름 | 사내 시스템 ID | 소속 팀 | 직책명'으로 보여 줍니다. 이미 등록된 사용자는 '등록됨' 배지를 달고 선택할 수 없습니다. 선택 목록의 [](선택 해제)로 고른 항목을 뺍니다. Alert에 추가 예정 · 이미 등록 인원을 보여 주고, 사용자 추가로는 역할을 부여하지 않습니다.
· 사용자 상세는 [조직 정보](기본) · [역할 정보] · [로그/이력] 탭이고, 브레드크럼은 '사용자 관리 > 이름'입니다. 기본 소속은 사내 사용자 정보 기준이라 수정할 수 없습니다.
· 계정 상태는 스위치로 바꿉니다. 스위치를 켜면 수동 활성화 Dialog, 끄면 수동 비활성화 Dialog가 열리고 수동 상태 종료일과 사유를 함께 정합니다(둘 다 필수). [취소]하면 스위치는 원래 상태로 돌아갑니다. 종료일이 지나면 사내 사용자 정보 기준 상태로 돌아가고, 계정 상태에 종료일과 사유를 보여 줍니다. 수동 상태 해제는 사용자 상세에 두지 않고 목록에서만 합니다. 로그인한 관리자 본인 계정은 스위치를 누를 수 없습니다. 수동 비활성화 Dialog는 [비활성화] · [취소] 순서이고 초기 포커스는 [취소]입니다.
· [역할 정보] 탭은 서비스 · 역할명 · 역할 상태(예약/활성/종료) · 출처(자동/수동) · 부여 방식 · 부여 대상 · 유효기간입니다. 별도 [편집] 버튼은 두지 않고, 역할명과 유효기간을 밑줄로 표시해 누르면 역할 편집 Dialog가 열립니다. 출처가 자동인 역할을 저장하면 수동 역할로 바뀝니다. 유효기간이 끝난(종료) 역할은 밑줄 없이 보여 주고 누를 수 없습니다. [역할 부여]는 서비스 역할 부여 Dialog를 엽니다. 수동으로 역할을 부여하거나 편집할 때(서비스 역할 부여 · 역할 편집)는 유효기간과 사유를 함께 정하고(둘 다 필수), 사유는 [로그/이력]에 남깁니다.
· 입력 중에 나가면 '저장하지 않은 내용이 사라집니다. 나가시겠습니까?'로 확인합니다([나가기] · [취소]).
· [로그/이력]에는 계정 상태 · 역할 · 소속 변경처럼 개인정보와 관계없는 이력만 남깁니다. 개인정보 조회 · 변경 · 다운로드 이력은 모두 운영 관리 › 감사로그에서 봅니다.
· 표시 기준: 사용자 관리의 이름 · 사내 시스템 ID · 이메일 · 등록 번호(CTN)는 원문으로 보여 줍니다(마스킹 여부 확인 필요). 날짜는 YYYY.MM.DD, 시간은 HH:mm입니다.

· [다운로드]는 표 밖 오른쪽 위에 둡니다. 누르면 다운로드 사유를 받고(사유 선택 · 직접 입력은 10자 이상), 다운로드한 기록도 사유와 함께 감사로그에 남깁니다.
