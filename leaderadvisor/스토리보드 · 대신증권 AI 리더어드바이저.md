### 기능 배치 기준
- 지식글 코멘트 관리는 지식 관리와 같은 메뉴입니다. 지식글 수정 요청 코멘트 처리는 KMS에서 하므로 지식 관리에서 KMS 팝업으로 넘깁니다. AI 추천 답변 좋아요/싫어요 피드백은 지식 관리에서 처리합니다.
- 코칭 요청과 실시간 코칭은 상담 어드바이저 · 리더 어드바이저에서 쪽지(팝업 창) 주고받기로 보여 주고, 이력은 알림에 쌓습니다. 코칭 요청 하단에 첨부 파일 영역을 둡니다.
- STT 단어사전 관리는 별도 STT 관리 메뉴에서 관리합니다(어드바이저 제외).
- 상품명 관리는 키워드 관리의 하위 탭입니다.
- 분석 기준 · 이력 관리는 BE 기능이라 화면에서 제외합니다.
- 권한 위임은 리더 어드바이저 설정에서 합니다.
- 상담사 VOC 추천 · 검색 · 등록 · 수정은 상담 어드바이저 메뉴에서 지원합니다.
- 화면 레이아웃 · 글자 크기는 상담 어드바이저 메뉴(화면 설정)에, 자동 추천 설정은 상담 어시스트 설정에 포함합니다.
- 복사 버튼은 복사 아이콘으로 표시합니다.
- 리더 어드바이저에는 상담직원 상태 · 콜타임 지연 · 멀티뷰 · 실시간 대화 · 콜 청취 · 코칭 요청을, 실시간 모니터링에는 상담 운영 현황 · 통화 발생 빈도를 둡니다.
- 멀티뷰는 리더 어드바이저 상담직원 목록에서 [대화 보기]를 누를 때마다 상담직원별 실시간 대화 팝업 창이 자동으로 열리는 방식입니다. 여러 명을 누르면 창이 여러 개 열립니다.
- 상담 어시스트 책갈피는 상담어드바이저와 리더어드바이저가 같은 화면입니다.
- 운영 관리 메뉴는 리더에게도 관리자와 같게 표시합니다.
- 실시간 대화의 NER 태그를 누르면 그 값이 메모에 기록됩니다.

범위 제외
- STT 단어사전 관리는 별도 STT 관리 메뉴에서 관리하므로 어드바이저 범위에 포함하지 않는다.
- 분석 기준 · 이력 관리는 BE 기능이라 화면 범위에 포함하지 않는다.
- 관리자 화면의 통화 분석 리포트는 이번 범위에 포함하지 않는다.
- 기간계에서 바꾼 상품 정보를 포털로 가져오는 방식(기간계 → 포털 연동, 양방향 연동)은 이번 범위에 포함하지 않는다. 상품 정보는 포털 상품 탭에서 등록·수정·삭제하고 기간계로 보낸다.

## 상담유형 분류

AI가 콜을 분석할 때 상담유형을 대분류 > 중분류 > 소분류 > 세분류 4단계로 자동 분류한다.

| 단계 | 설명 |
| --- | --- |
| 대분류 | 가장 상위 분류 |
| 중분류 | 대분류의 하위 분류 |
| 소분류 | 중분류의 하위 분류 |
| 세분류 | 소분류의 하위 분류. 가장 상세한 분류 |

- 화면에는 '대분류 > 중분류 > 소분류 > 세분류' 경로로 표시한다.
- 하위 단계까지 분류하지 못한 콜은 분류된 단계까지만 표시한다. (예: 계좌 > 계좌개설) (확인 필요)
- 분류는 콜 분석 시점에 수행한다. 분류 체계가 바뀌어도 이미 분석된 콜은 다시 분류하지 않는다. (확인 필요)
- 사용자는 분류 결과를 수정할 수 없다.

| 화면 | 활용 방식 |
| --- | --- |
| 상담이력 목록 | '상담유형' 컬럼에 분류 경로 표시 |
| 상담이력 상세 | 콜 기본 정보의 '상담유형'에 분류 경로, '분류 결과' 영역에 단계별 분류 표시 |
| 키워드 관리 | 키워드의 '연관 상담유형' 선택지로 사용 |

## 키워드 유형

키워드 유형은 기본 3개(상품·리스크·제외 키워드)이고, 키워드 관리에서 [유형 추가]로 유형을 추가할 수 있다. 유형 하나가 키워드 관리의 탭 하나다.

키워드 관리의 탭과 상담이력의 키워드 유형 드롭다운은 같은 유형을 같은 순서로 사용한다. 추가한 유형은 기본 3개 뒤에 추가한 순서로 표시한다.

| 순서 | 키워드 유형 | 관리 항목 | 설명 |
| --- | --- | --- | --- |
| 1 | 상품 | 상품 코드·상품명·설명·사용상태(기간계로 전송), 연관 키워드 | 포털에서 등록해 기간계로 보내는 상품과 상품별 연관 키워드 |
| 2 | 리스크 | 키워드·설명·연관 상담유형 | 리스크로 관리할 표현 |
| 3 | 제외 키워드 | 키워드·설명·연관 상담유형 | 용도 확인 필요 |
| 4~ | 추가한 유형 | 키워드·설명·연관 상담유형 | 키워드 관리에서 [유형 추가]로 만든 유형 |

### 키워드 태그 (상담 키워드·이슈 키워드)

BE는 콜에서 추출한 키워드를 상담 키워드와 이슈 키워드로 따로 태깅한다. 키워드 태그는 키워드 유형과 별개 기준이며, 이슈 키워드는 리스크 유형 키워드와 다르다.

| 구분 | 키워드 유형 | 키워드 태그 |
| --- | --- | --- |
| 값 | 상품 / 리스크 / 제외 키워드 / 추가한 유형 | 상담 키워드 / 이슈 키워드 |
| 지정 주체 | 사용자가 키워드 관리에서 등록 (상품 정보는 등록 후 기간계로 전송) | BE가 콜 분석 시 태깅 |

## 상담이력 조회

상담이력 조회 메뉴의 하위 메뉴는 상담이력(목록·상세)과 이슈 콜 목록이다.

### 상담이력 목록

#### 화면 구성

| 영역 | 구성 |
| --- | --- |
| 필터 | 기간·센터·팀·사번·통화시간·재인입·키워드(키워드 유형 드롭다운 + 키워드 입력), [초기화] [검색] |
| 목록 상단 | 총 n건, 페이지 크기 드롭다운(10/20/50) |
| 목록 테이블 | 아래 '목록 컬럼' 참고, 컬럼 헤더 클릭으로 정렬 |
| 페이지네이션 | 처음·이전·페이지 번호·다음·마지막 |

#### 필터 (다중 필터)

서로 다른 필터는 AND로, 한 필터 안의 다중 선택은 OR로 결합한다.

| 필터 | 컴포넌트 | 기본값 | 동작·조건 |
| --- | --- | --- | --- |
| 기간 | 시작일~종료일 달력 + 빠른 선택(오늘·최근 7일·최근 30일) | 오늘 (확인 필요) | yyyy.mm.dd ~ yyyy.mm.dd로 표시. 종료일은 시작일 이후만 선택 가능 |
| 센터 | 다중 선택 드롭다운 | 전체 | 조회 권한이 있는 센터만 노출 |
| 팀 | 다중 선택 드롭다운 | 전체 | 선택한 센터에 속한 팀만 노출. 센터를 바꾸면 범위를 벗어난 팀 선택은 해제 |
| 사번 | 텍스트 입력 | 빈값 | 쉼표(,)로 여러 사번 입력 (확인 필요) |
| 통화시간 | 최소~최대 입력(mm:ss) | 빈값 | 최소만 입력하면 이상, 최대만 입력하면 이하 조건 |
| 재인입 | 단일 선택 드롭다운(전체 / 재인입 / 비재인입) | 전체 | - |
| 키워드 | 키워드 유형 드롭다운(상품 / 리스크 / 제외 키워드 / 추가한 유형) + 키워드 텍스트 입력 | 키워드 유형: 미선택 / 키워드: 빈값 | 키워드 유형을 선택해야 키워드 입력칸이 활성화된다. 선택한 유형으로 감지된 키워드 중 입력값과 일치하는 키워드가 있는 콜을 조회한다. 제외 키워드를 선택해도 같은 방식으로 해당 키워드가 감지된 콜을 조회한다. 키워드를 비워 두면 키워드 조건 없이 검색한다 |

키워드 입력칸 안내 문구
- 키워드 유형 미선택: 키워드 유형을 먼저 선택해 주세요. (입력칸 비활성)
- 키워드 유형 선택 후: 키워드를 입력해 주세요.

| 버튼 | 동작 |
| --- | --- |
| [검색] | 현재 필터로 검색 후 1페이지로 이동. 정렬·페이지 크기는 유지. 키워드 입력칸에서 Enter를 눌러도 같은 동작 |
| [초기화] | 모든 필터를 기본값으로 되돌린 뒤 다시 검색 |

| 입력 오류 | 안내 문구 |
| --- | --- |
| 기간 미선택 | 조회 기간을 선택해 주세요. |
| 최대 조회 기간 초과 | 조회 기간은 최대 n일까지 선택할 수 있습니다. (n 확인 필요) |
| 통화시간 형식 오류 | 통화시간은 mm:ss 형식으로 입력해 주세요. |

정렬
- 컬럼 헤더를 클릭하면 오름차순과 내림차순이 번갈아 적용된다.
- 정렬 중인 컬럼에는 방향 아이콘(▲/▼)을, 정렬 가능한 나머지 컬럼에는 ⇅ 아이콘을 표시한다.
- 한 번에 한 컬럼 기준으로만 정렬한다.
- 정렬을 바꾸면 1페이지로 이동하고, 필터·페이지 크기는 유지한다.

페이지 크기
- 선택값은 10 / 20 / 50이고, 기본값은 20이다. (확인 필요)
- 페이지 크기를 바꾸면 1페이지로 이동하고, 필터·정렬은 유지한다.

행 클릭: 해당 콜의 상담이력 상세로 이동한다.

- 발화 사이의 묵음 구간은 '묵음 mm:ss' 구분선으로 표시한다.

#### 추출 키워드

- 영역 상단에 키워드 유형 드롭다운(전체 / 상품 / 리스크 / 제외 키워드 / 추가한 유형)을 둔다. 기본값은 '전체'다.
- 키워드별로 키워드명, 키워드 유형, 발생 횟수, 발생 시점(mm:ss)을 표시한다.
- 발생 횟수 내림차순으로 정렬한다. (확인 필요)
- 키워드명을 클릭하면 첫 발생 발화로 전사 텍스트를 스크롤하고 녹취를 해당 시점으로 이동한다.

| --- | --- |
| 추출 키워드 없음 | 추출된 키워드가 없습니다. |
| 선택한 유형의 키워드 없음 | 선택한 유형에 해당하는 키워드가 없습니다. |

| 이슈 키워드 | BE가 이슈 키워드로 태깅한 키워드 수와 목록 | 1건 이상 감지 (확인 필요) |

- 이슈 키워드는 키워드 유형 '리스크'와 별개다.
- 기준을 넘은 지표는 '주의' 배지로 강조한다.
- 시점이 있는 지표(묵음 구간, 이슈 키워드)는 클릭하면 녹취·전사 텍스트와 연계된다.
- 감지된 지표가 없으면 '감지된 이상 지표가 없습니다.'를 표시한다.

### 상담이력 정책

- 로그인 사용자 역할의 데이터 조회 범위(역할 관리 설정)에 속한 콜만 조회·열람할 수 있다.
- 상세에서 [목록으로] 또는 브라우저 뒤로가기로 돌아오면 필터·정렬·페이지 크기·페이지 번호를 유지한다.
- 전사 텍스트·분류 결과·추출 키워드·이상 지표는 열람만 가능하다.
- 상담이력 목록 검색과 상세 키워드 표시는 콜 분석 시점에 감지된 키워드를 기준으로 한다. 이후 키워드 관리에서 키워드를 등록·수정·삭제해도 이미 분석된 콜의 키워드는 바뀌지 않는다.

### 이슈 콜 목록

상담이력 조회의 하위 메뉴다. BE가 이슈 키워드를 태깅한 콜(이슈 콜)을 모아 보여주고, 이슈 콜마다 처리 상태·이슈 기한·담당 관리자·처리 내역을 관리한다. 상담어드바이저와 리더어드바이저에 같은 화면을 제공하고, 리더어드바이저에만 [설정]을 추가로 표시한다.

#### 이슈 콜 등록

- BE가 콜을 분석할 때 이슈 키워드를 1건 이상 태깅하면 그 콜을 이슈 콜 목록에 자동으로 등록한다. 이슈 콜의 정의는 콜 통계의 '이슈 콜'과 같다.
- 등록할 때 상태는 '미처리', 이슈 기한은 이슈 콜 설정 '기간' 탭의 기본 이슈 기한, 이슈 유형과 담당 관리자는 '미지정'이다.
- 사용자가 이슈 콜을 직접 추가하거나 목록에서 삭제하는 기능은 제공하지 않는다. 확인 결과 이슈가 아니면 상태를 '이슈없음'으로 바꾼다.

#### 화면 구성

| 영역 | 구성 |
| --- | --- |
| 상단 | 화면명 '이슈 콜 목록'. 리더어드바이저에서는 오른쪽 끝에 [설정] |
| 필터 | 기간·센터·팀·상담사·이슈 키워드·상태·이슈 기한·기한 초과·이슈 유형·담당 관리자, [초기화] [검색] |
| 목록 상단 | 총 n건, 상태별 건수(미처리 n건 · 검토필요 n건 · 처리완료 n건 · 이슈없음 n건) + 기한 초과 n건, [상태 변경] [기한 지정] [담당 관리자 지정], 페이지 크기 드롭다운(10/20/50) |
| 목록 테이블 | 아래 '이슈 콜 목록 컬럼' 참고, 컬럼 헤더 클릭으로 정렬 |
| 페이지네이션 | 처음·이전·페이지 번호·다음·마지막 |

- 상태별 건수를 클릭하면 상태 필터를 그 상태로 바꿔 검색한다. '기한 초과 n건'을 클릭하면 '기한 초과만 보기'를 켜고 검색한다.
- [상태 변경]·[기한 지정]·[담당 관리자 지정]은 이슈 콜 목록 편집 권한이 있을 때만 표시한다.
- 리더어드바이저에서 이슈 콜 설정 편집 권한이 있으면 이슈 유형 필터 옆에 [이슈 유형 관리]를 표시한다. 누르면 이슈 콜 설정 '이슈 유형' 탭으로 이동한다.

#### 필터 (다중 검색)

서로 다른 필터는 AND로, 한 필터 안의 다중 선택은 OR로 결합한다.

| 필터 | 컴포넌트 | 기본값 | 동작·조건 |
| --- | --- | --- | --- |
| 기간 | 시작일~종료일 달력 + 빠른 선택(오늘·최근 7일·최근 30일) | 최근 7일 (확인 필요) | 통화 일시 기준. yyyy.mm.dd ~ yyyy.mm.dd로 표시. 종료일은 시작일 이후만 선택 가능 |
| 센터 | 다중 선택 드롭다운 | 전체 | 조회 권한이 있는 센터만 노출 |
| 팀 | 다중 선택 드롭다운 | 전체 | 선택한 센터에 속한 팀만 노출. 센터를 바꾸면 범위를 벗어난 팀 선택은 해제 |
| 상담사 | 텍스트 입력(사번 또는 이름) | 빈값 | 부분 일치 |
| 이슈 키워드 | 텍스트 입력 | 빈값 | 입력값이 포함된 이슈 키워드가 태깅된 콜을 조회 (부분 일치) |
| 상태 | 다중 선택 드롭다운(미처리 / 검토필요 / 처리완료 / 이슈없음) | 전체 (확인 필요) | - |
| 이슈 기한 | 다중 선택 드롭다운(일 / 주 / 월 / 연) | 전체 | - |
| 기한 초과 | 체크박스 '기한 초과만 보기' | 해제 | 처리 전('미처리'·'검토필요')이면서 기한일이 지난 이슈 콜만 조회 |
| 이슈 유형 | 다중 선택 드롭다운. 이슈 콜 설정에 등록된 이슈 유형 + 미지정 | 전체 | - |
| 담당 관리자 | 다중 선택 드롭다운. 이슈 콜 설정에 등록된 담당자 + 미지정 | 전체 | - |

- [검색]·[초기화] 동작과 기간 입력 오류 문구는 상담이력 목록과 같다.
- 상담어드바이저에서 상담사 역할 사용자에게는 상담사 공개 범위(이슈 콜 설정 '공개 범위' 탭)에 맞춰 필터를 줄인다. '본인'이면 센터·팀·상담사 필터를, '센터'면 센터 필터를 표시하지 않는다.

#### 이슈 콜 목록 컬럼

| 컬럼 | 표시 기준 | 정렬 |
| --- | --- | --- |
| 선택 | 체크박스. 편집 권한이 있을 때만 표시. 헤더 체크박스는 현재 페이지 전체 선택 | - |
| 콜 ID | 콜 고유 식별값 | 가능 |
| 일시 | 통화 일시(yyyy.mm.dd HH:mm:ss) | 가능 · 기본 정렬(내림차순) |
| 센터/팀 | '센터명 / 팀명' | 가능 |
| 상담사 | 상담사명(사번) | 가능 |
| 통화시간 | HH:mm:ss | 가능 |
| 이슈 키워드 | 태깅된 이슈 키워드. 최대 3개 노출 후 '+n', 마우스 오버 시 전체 키워드 툴팁 | - |
| 이슈 유형 | 지정된 이슈 유형. 없으면 '미지정' | 가능 |
| 상태 | '미처리' / '검토필요' / '처리완료' / '이슈없음' 배지 | 가능 |
| 이슈 기한 | 이슈 기한 드롭다운(일 / 주 / 월 / 연)과 기한일(yyyy.mm.dd). 처리 전이면서 기한일이 지났으면 '기한 초과' 배지. 편집 권한이 없으면 드롭다운 대신 텍스트로 표시 | 가능 (기한일 기준) |
| 담당 관리자 | 담당 관리자 이름. 없으면 '미지정' | 가능 |

- 정렬과 페이지 크기는 상담이력 목록과 같은 방식으로 동작한다.
- 행을 클릭하면 해당 콜의 상담이력 상세로 이동하고, '이슈 처리' 영역을 함께 표시한다.
- 이슈 기한 드롭다운에서 값을 고르면 바로 저장하고 기한일을 다시 계산한 뒤 토스트 '이슈 기한을 변경했습니다.'를 표시한다. 드롭다운을 누를 때는 상세로 이동하지 않는다.

#### 상태

| 상태 | 의미 | 처리 완료일 |
| --- | --- | --- |
| 미처리 | 이슈 콜로 등록되고 아직 확인하지 않은 상태. 등록할 때 기본값 | 기록하지 않음 |
| 검토필요 | 확인했지만 추가 검토가 필요한 상태 | 기록하지 않음 |
| 처리완료 | 필요한 조치를 마친 상태 | 상태를 바꾼 날짜로 기록 |
| 이슈없음 | 확인 결과 이슈가 아닌 상태 | 상태를 바꾼 날짜로 기록 (확인 필요) |

- 상태는 순서와 관계없이 바꿀 수 있다. (확인 필요)
- '처리완료'나 '이슈없음'에서 '미처리'나 '검토필요'로 되돌리면 처리 완료일을 지운다. 다시 '처리완료'나 '이슈없음'으로 바꾸면 그 날짜로 다시 기록한다.

#### 이슈 기한

이슈 콜을 처리해야 하는 기한이다. 이슈 기한 드롭다운(일 / 주 / 월 / 연)에서 고른다. 기한일은 달력 기준으로, 이슈 콜 등록일이 속한 날·주·월·연의 마지막 날이다.

| 이슈 기한 | 기한일 | 예시 (등록일 2026.11.05 목요일) |
| --- | --- | --- |
| 일 | 등록일 당일 | 2026.11.05 |
| 주 | 등록일이 속한 주의 일요일 (주는 월요일~일요일) | 2026.11.08 |
| 월 | 등록일이 속한 달의 말일 | 2026.11.30 |
| 연 | 등록일이 속한 해의 12월 31일 | 2026.12.31 |

- 새로 등록되는 이슈 콜의 이슈 기한은 이슈 콜 설정 '기간' 탭의 기본 이슈 기한이다.
- 이슈 기한은 목록의 이슈 기한 드롭다운, [기한 지정](일괄), 상담이력 상세의 이슈 처리 영역에서 바꿀 수 있다.
- 이슈 기한을 바꾸면 등록일이 속한 기간을 기준으로 기한일을 다시 계산한다. (확인 필요)
- 기간 끝 무렵에 등록된 이슈 콜은 처리할 수 있는 날이 짧다. 예를 들어 일요일에 등록한 이슈 콜의 '주' 기한은 등록 당일이다.
- 기한일 당일까지는 기한 내로 본다. 상태가 '미처리'·'검토필요'인데 오늘이 기한일보다 뒤면 '기한 초과'로 표시한다.
- '처리완료'·'이슈없음'이면 기한 초과 배지를 표시하지 않는다. 처리 완료일이 기한일보다 뒤면 콜 통계에서 기한 내 처리로 세지 않는다.

#### 일괄 처리

| 사용자 동작 | 시스템 동작 |

- 선택한 이슈 콜이 없으면 [상태 변경]·[기한 지정]·[담당 관리자 지정]은 비활성이다.

### 이슈 처리 (상담이력 상세)

이슈 콜의 상담이력 상세에는 분석 결과 영역 위에 '이슈 처리' 영역을 표시한다. 이슈 콜이 아니면 표시하지 않는다. 이슈 콜 목록에서 들어오지 않고 상담이력 목록에서 들어와도 같은 영역을 표시한다.

| 요소 | 내용 |
| --- | --- |
| 상태 | 드롭다운(미처리 / 검토필요 / 처리완료 / 이슈없음) |
| 이슈 기한 | 드롭다운(일 / 주 / 월 / 연) + 기한일(yyyy.mm.dd). 기한 초과면 '기한 초과' 배지 |
| 이슈 유형 | 드롭다운. 이슈 콜 설정에서 '사용'으로 둔 이슈 유형. 이슈 콜 설정 편집 권한이 있으면 목록 맨 아래에 [+ 이슈 유형 추가] |
| 담당 관리자 | 드롭다운. 이슈 콜 설정에 등록된 담당자. 선택한 이슈 유형을 담당하는 사람을 위쪽에 표시 |
| 개선 제안 | 선택한 이슈 유형에 등록된 개선 제안 목록. 제안마다 [처리 내용에 넣기] |
| 처리 내용 | 여러 줄 텍스트 입력. 안내 문구 '처리 내용을 입력해 주세요.' 상태를 '처리완료'·'이슈없음'으로 바꿀 때 필수 (제안) |
| 처리 완료일 | 자동 기록(yyyy.mm.dd). 직접 입력할 수 없음 |
| 버튼 | [저장]. 바꾼 값이 없으면 비활성. 저장하면 토스트 '변경사항이 저장되었습니다.' 표시 |
| 처리 내역 | 아래 '처리 내역' 참고 |

- 이슈 유형을 지정하지 않으면 개선 제안 영역에 '이슈 유형을 선택하면 개선 제안을 볼 수 있습니다.'를 표시한다.
- [+ 이슈 유형 추가]를 누르면 이슈 콜 설정 '이슈 유형' 탭과 같은 이슈 유형 추가 모달을 표시한다. 추가하면 새 이슈 유형을 바로 선택한다.
- 편집 권한이 없는 사용자에게는 이슈 처리 영역을 읽기 전용으로 표시한다.
- 다른 사용자가 먼저 저장한 뒤 저장하면 '다른 사용자가 먼저 변경했습니다. 화면을 새로 고친 뒤 다시 시도해 주세요.'를 표시한다.

| --- | --- |
| '처리완료'·'이슈없음'인데 처리 내용 없음 | 처리 내용을 입력해 주세요. |
| 저장 실패 | 저장하지 못했습니다. 다시 시도해 주세요. |

### 이슈 콜 설정 (리더어드바이저)

리더어드바이저 이슈 콜 목록의 [설정]으로 들어가는 화면이다. 상담어드바이저에는 [설정]을 표시하지 않는다. 이슈 콜 설정 편집 권한이 있는 역할만 들어갈 수 있다.

| 탭 | 관리 항목 | 쓰이는 곳 |

### 이슈 콜 정책

- 이슈 콜 목록은 로그인 사용자 역할의 데이터 조회 범위에 속한 콜만 표시한다. 단, 상담어드바이저의 상담사 역할 사용자는 이슈 콜 설정의 상담사 공개 범위(본인 / 센터 / 전체)를 따른다.
- 상태 변경, 이슈 기한·이슈 유형·담당 관리자 지정, 처리 내용 저장은 이슈 콜 목록 편집 권한이 있는 역할만 할 수 있다.
- 이슈 콜 등록 여부는 콜 분석 시점의 이슈 키워드 태깅 결과를 기준으로 한다. 이후 키워드가 바뀌어도 이미 등록된 이슈 콜은 그대로 둔다.
- 처리 내역은 이슈 콜마다 남기며 수정·삭제할 수 없다. 같은 작업은 감사로그에도 기록한다.
- 상세에서 [목록으로]나 브라우저 뒤로가기로 이슈 콜 목록에 돌아오면 필터·정렬·페이지 크기·페이지 번호를 유지한다.
- 상담어드바이저와 리더어드바이저는 같은 이슈 콜 데이터를 쓴다. 두 포털의 차이는 [설정]·[이슈 유형 관리] 표시 여부와, 상담어드바이저 상담사에게 적용되는 공개 범위다.

## 키워드 관리

### 화면 구성

| 영역 | 구성 |
| --- | --- |
| 상단 | 화면명 '키워드 관리' |
| 안내 문구 | 등록·수정·삭제한 키워드는 이후 분석되는 콜부터 적용됩니다. 이미 분석된 콜에는 적용되지 않습니다. |
| 탭 | 상품 / 리스크 / 제외 키워드 / 추가한 유형. 탭명 옆에 건수 표시(예: 상품 (24)). 탭 영역 오른쪽 끝에 [+ 유형 추가] |
| 탭 내용 | 상품 탭은 '상품 탭', 그 밖의 탭은 '키워드 탭' 구성을 따른다 |

### 탭

| 탭 | 구성 | 관리 항목 |
| --- | --- | --- |
| 상품 | 상품 탭 | 상품 코드·상품명·설명·사용상태(기간계로 전송), 연관 키워드 |
| 리스크 | 키워드 탭 | 키워드·설명·연관 상담유형 |
| 제외 키워드 | 키워드 탭 | 키워드·설명·연관 상담유형 |
| 추가한 유형 | 키워드 탭 | 키워드·설명·연관 상담유형 |

- 탭 순서는 상품 → 리스크 → 제외 키워드 → 추가한 유형(추가한 순서)다.
- 기본 탭은 '상품'이다.
- 탭 건수는 상품 탭이면 등록된 상품 수, 키워드 탭이면 등록된 키워드 수다.
- 탭을 바꾸면 탭 내 검색 조건과 체크박스 선택을 초기화하고 1페이지로 이동한다.
- 모든 탭에서 정렬과 페이지 크기는 상담이력 목록과 같은 방식으로 동작한다. 페이지 크기 기본값은 20이다. (확인 필요)

### 상품 탭

상품 탭에서 상품(상품 코드·상품명·설명·사용상태)을 등록·수정·삭제하고, 상품마다 연관 키워드를 함께 등록해 상품과 키워드를 매핑한다. 상품 정보의 원본은 포털이며, 등록·수정·삭제한 상품 정보는 기간계로 보낸다.

#### 기간계 전송

| 항목 | 내용 |
| --- | --- |
| 전송 방향 | 포털 → 기간계 단방향 |
| 전송 항목 | 상품 코드·상품명·설명·사용상태. 연관 키워드는 보내지 않는다 |
| 전송 시점 | 상품을 등록·수정·삭제해 저장할 때 보낸다. 실시간 전송인지 배치 전송인지는 확인 필요 |
| 저장 방식 | 포털에 먼저 저장한 뒤 기간계로 보낸다. 기간계 반영에 실패해도 포털에 저장한 내용은 유지한다 (확인 필요) |
| 기간계 반영 상태 | 상품마다 '반영 완료' / '반영 대기' / '반영 실패'를 표시한다. 대기·실패에는 요청 종류를 함께 표시한다 (예: 수정 반영 대기, 삭제 반영 실패) |

#### 상품 탭 정책

- 상품 정보의 원본은 포털 상품 탭이다. 등록·수정·삭제한 상품 정보는 기간계로 보낸다.
- 기간계에서 바꾼 상품 정보는 포털로 가져오지 않는다.
- 상품 코드는 중복 등록할 수 없고, 등록한 뒤에는 바꿀 수 없다.
- 반영 대기 중인 상품은 상품 정보를 수정·삭제할 수 없다. 연관 키워드는 수정할 수 있다.
- 연관 키워드는 기간계로 보내지 않고 포털에서만 관리한다. STT 인식 키워드와도 별개다. 연관 키워드를 등록·수정·삭제해도 STT 인식 키워드는 바뀌지 않는다.
- 같은 상품 안에서는 같은 연관 키워드를 중복 등록할 수 없다.
- 키워드 감지는 기간계 반영 상태와 관계없이 포털에 저장된 상품과 연관 키워드로 동작한다. (확인 필요)
- 사용상태가 '미사용'인 상품의 연관 키워드를 감지에 계속 쓸지는 확인 필요.
- 상품 등록·수정·삭제와 기간계 전송·재전송 결과는 감사로그에 기록한다.

| 키워드 빈값 | 키워드가 비어 있습니다. |
| 같은 유형에 이미 등록된 키워드 | 이미 등록된 키워드입니다. |
| 파일 안에서 같은 키워드가 반복됨 | 파일 안에 같은 키워드가 있습니다. |

| 없는 상담유형 | 존재하지 않는 상담유형입니다. |

- 파일 안에서 같은 키워드가 반복되면 첫 행만 등록하고 나머지 행은 실패로 처리한다.

| 파일 오류 | 안내 문구 |

| 최대 건수 초과 | 한 번에 최대 n건까지 등록할 수 있습니다. (n 확인 필요) |
| 등록할 행 없음 | 등록할 키워드가 없습니다. |

| 상황 | 표시 |

| 등록·수정·삭제 실패 | 저장하지 못했습니다. 다시 시도해 주세요. |

### 유형 추가

[유형 추가]로 키워드 유형을 추가하면 키워드 관리에 탭이 하나 생기고, 상담이력의 키워드 유형 드롭다운에도 같은 유형이 추가된다.

| 요소 | 내용 |
| --- | --- |
| 위치 | 탭 영역 오른쪽 끝 [+ 유형 추가] |
| 제목 | 유형 추가 |
| 유형명 (필수) | 텍스트 입력. 안내 문구 '유형명을 입력해 주세요.' |
| 보조 문구 | 추가한 유형은 상담이력의 키워드 유형에도 표시됩니다. |
| 버튼 | [취소] [추가]. 유형명을 입력하기 전에는 [추가] 비활성 |
| 추가 완료 | 모달을 닫고 마지막 탭 뒤에 새 탭을 추가해 이동, 토스트 '유형이 추가되었습니다.' 표시 |

| 입력 오류 | 안내 문구 |
| --- | --- |
| 이미 있는 유형명 | 이미 있는 유형명입니다. |
| 최대 글자 수 초과 | 유형명은 최대 n자까지 입력할 수 있습니다. (n 확인 필요) |
| 최대 개수 초과 | 유형은 최대 n개까지 추가할 수 있습니다. (n 확인 필요) |
| 추가 실패 | 저장하지 못했습니다. 다시 시도해 주세요. |

- 추가한 유형은 키워드 탭 구성(키워드·설명·연관 상담유형, 엑셀 일괄 등록)을 쓴다.
- 기본 유형(상품·리스크·제외 키워드)은 이름을 바꾸거나 삭제할 수 없다.
- 추가한 유형의 이름 변경·삭제 제공 여부는 확인 필요.

### 키워드 관리 정책

- 키워드 유형은 상품·리스크·제외 키워드 3개를 기본으로 제공하고, [유형 추가]로 늘릴 수 있다.
- 키워드 탭에서는 같은 유형 안에 같은 키워드를 중복 등록할 수 없다.
- 키워드·연관 키워드·유형명의 앞뒤 공백은 제거하고 저장한다.
- 등록한 키워드의 유형은 바꿀 수 없다. 다른 유형으로 옮기려면 삭제한 뒤 해당 탭에서 다시 등록한다.
- 키워드·연관 키워드 등록·수정·삭제(엑셀 일괄 등록 포함), 유형 추가, 상품 등록·수정·삭제는 변경 이후 분석되는 콜부터 반영한다. 이미 분석된 과거 콜에는 소급 적용하지 않는다.

## 콜 통계

관리자 화면 메뉴다. 선택한 조건에 해당하는 전체 콜·재인입 콜·이슈 콜 건수와 평균 통화시간·평균 묵음시간을 보여준다. 이슈 콜 목록의 처리 상태를 모은 '이슈 콜 처리 현황'도 함께 보여준다.

### 화면 구성

| 영역 | 구성 |
| --- | --- |
| 상단 | 화면명 '콜 통계', 집계 기준 일시(yyyy.mm.dd HH:mm:ss) |
| 필터 | 기간·센터·팀, [초기화] [검색] |
| 요약 카드 | 전체 콜 / 재인입 콜 / 이슈 콜 / 평균 통화시간 / 평균 묵음시간 |
| 통계 표 | 집계 단위 드롭다운(일자별 / 센터별 / 팀별) + 집계 단위별 지표 표 |
| 이슈 콜 처리 현황 | 상태별 요약 카드 + 처리 현황 표(기간별 / 이슈 유형별 / 담당 관리자별). 아래 '이슈 콜 처리 현황' 참고 |

### 필터

| 필터 | 컴포넌트 | 기본값 | 동작·조건 |
| --- | --- | --- | --- |
| 기간 | 시작일~종료일 달력 + 빠른 선택(오늘·최근 7일·최근 30일) | 최근 7일 (확인 필요) | yyyy.mm.dd ~ yyyy.mm.dd로 표시. 종료일은 시작일 이후만 선택 가능 |
| 센터 | 다중 선택 드롭다운 | 전체 | 조회 권한이 있는 센터만 노출 |
| 팀 | 다중 선택 드롭다운 | 전체 | 선택한 센터에 속한 팀만 노출. 센터를 바꾸면 범위를 벗어난 팀 선택은 해제 |

- [검색]을 클릭하면 요약 카드와 통계 표를 함께 갱신한다.
- [초기화]를 클릭하면 필터를 기본값으로 되돌린 뒤 다시 검색한다.
- 기간 미선택·최대 조회 기간 초과 안내 문구는 상담이력 목록과 같다.

### 지표 정의

| 지표 | 정의 | 산식 | 표시 형식 |
| --- | --- | --- | --- |
| 전체 콜 | 조회 조건에 해당하는 콜 | 콜 수 | 1,234건 |
| 재인입 콜 | 전체 콜 중 재인입으로 판정된 콜 | 재인입 콜 수 | 1,234건 |
| 이슈 콜 | 전체 콜 중 BE가 이슈 키워드로 태깅한 키워드가 1건 이상 있는 콜 (확인 필요). 이슈 콜 목록에 등록되는 콜과 같고, '이슈없음'으로 처리한 콜도 포함한다 | 이슈 콜 수 | 1,234건 |
| 평균 통화시간 | 콜 1건당 평균 통화시간 | 통화시간 합계 ÷ 전체 콜 수 | HH:mm:ss |
| 평균 묵음시간 | 콜 1건당 평균 묵음시간 | 묵음시간 합계 ÷ 전체 콜 수 (분모 확인 필요) | HH:mm:ss |

집계 기준
- 콜은 통화 일시가 조회 기간에 포함되면 집계한다.
- 재인입·묵음 판정 기준은 상담이력과 같다.
- 한 콜이 재인입 콜이면서 이슈 콜일 수 있다. 따라서 재인입 콜과 이슈 콜 건수를 더한 값은 전체 콜과 다를 수 있다.
- 평균 시간은 초 미만을 반올림해 표시한다.
- 전체 콜이 0건이면 평균 시간은 '-'로 표시한다.
- 데이터 갱신 주기는 확인 필요.

### 요약 카드

- 카드 5개(전체 콜, 재인입 콜, 이슈 콜, 평균 통화시간, 평균 묵음시간)에 지표명과 값을 표시한다.
- 값은 현재 필터 조건 전체를 기준으로 계산한다.

### 통계 표

| 컬럼 | 표시 기준 | 정렬 |
| --- | --- | --- |
| 집계 단위 | 일자별: 날짜(yyyy.mm.dd) / 센터별: 센터명 / 팀별: 센터명·팀명 | 가능 · 기본 정렬(일자별은 날짜 내림차순, 센터별·팀별은 이름 오름차순) |
| 전체 콜 | 건수 | 가능 |
| 재인입 콜 | 건수 | 가능 |
| 이슈 콜 | 건수 | 가능 |
| 평균 통화시간 | HH:mm:ss | 가능 |
| 평균 묵음시간 | HH:mm:ss | 가능 |

- 집계 단위 기본값은 일자별이다. (확인 필요) 집계 단위를 바꾸면 현재 필터로 표를 바로 다시 집계한다.
- 표 맨 위에 '합계' 행을 고정하고 요약 카드와 같은 값을 표시한다. 합계 행의 평균 시간은 행별 평균의 평균이 아니라 전체 콜 기준으로 계산한다.
- 정렬 방식은 상담이력 목록과 같다. 합계 행은 정렬 대상에서 제외한다.
- 일자별에서는 콜이 없는 날짜도 행을 표시한다. 건수는 0건, 평균 시간은 '-'로 표시한다.
- 페이지네이션 없이 전체 행을 표시한다.

### 이슈 콜 처리 현황

이슈 콜 목록의 상태·이슈 기한·이슈 유형·담당 관리자·처리 완료일을 집계한다. 기간·센터·팀은 콜 통계 필터를 같이 쓴다.

#### 지표 정의

| 지표 | 정의 | 산식 | 표시 형식 |
| --- | --- | --- | --- |
| 미처리 | 이슈 콜 중 현재 상태가 '미처리'인 콜 | 콜 수 | 1,234건 |
| 검토필요 | 이슈 콜 중 현재 상태가 '검토필요'인 콜 | 콜 수 | 1,234건 |
| 처리완료 | 이슈 콜 중 현재 상태가 '처리완료'인 콜 | 콜 수 | 1,234건 |
| 이슈없음 | 이슈 콜 중 현재 상태가 '이슈없음'인 콜 | 콜 수 | 1,234건 |
| 확정 이슈 콜 | 이슈 콜 중 '이슈없음'을 뺀 콜 | 이슈 콜 수 − 이슈없음 수 | 1,234건 |
| 처리율 | 이슈 콜 중 처리를 마친 콜의 비율 | (처리완료 수 + 이슈없음 수) ÷ 이슈 콜 수 × 100 | 87.5% |
| 평균 처리 기간 | 이슈 콜 등록일부터 처리 완료일까지 걸린 평균 일수 | (처리 완료일 − 이슈 콜 등록일) 합계 ÷ (처리완료 수 + 이슈없음 수) | 2.5일 |
| 기한 초과 | 처리 전('미처리'·'검토필요')이면서 기한일이 지난 이슈 콜 | 콜 수 | 1,234건 |
| 기한 내 처리율 | 처리를 마친 이슈 콜 중 기한일까지 처리한 콜의 비율 | 처리 완료일이 기한일 이전이거나 같은 콜 수 ÷ (처리완료 수 + 이슈없음 수) × 100 | 87.5% |

집계 기준
- 이슈 콜은 통화 일시가 조회 기간에 포함되면 집계한다. 콜 통계 요약 카드의 '이슈 콜'과 같은 대상이다.
- 상태는 조회 시점의 현재 상태를 기준으로 한다. (확인 필요)
- 평균 처리 기간은 같은 날 처리하면 0일로 계산한다.
- 이슈 콜이 0건이면 처리율은 '-'로, 처리를 마친 콜이 0건이면 평균 처리 기간과 기한 내 처리율은 '-'로 표시한다.

#### 요약 카드

- 카드 9개(미처리, 검토필요, 처리완료, 이슈없음, 확정 이슈 콜, 처리율, 평균 처리 기간, 기한 초과, 기한 내 처리율)에 지표명과 값을 표시한다.
- 값은 현재 필터 조건 전체를 기준으로 계산한다.

#### 처리 현황 표

| 컬럼 | 표시 기준 | 정렬 |
| --- | --- | --- |
| 집계 단위 | 기간별: 일은 yyyy.mm.dd, 주·월·연은 yyyy.mm.dd ~ yyyy.mm.dd / 이슈 유형별: 이슈 유형명(미지정 포함) / 담당 관리자별: 이름(미지정 포함) | 가능 · 기본 정렬(기간별은 최근 기간부터, 그 밖에는 이슈 콜 많은 순) |
| 이슈 콜 | 건수 | 가능 |
| 미처리 | 건수 | 가능 |
| 검토필요 | 건수 | 가능 |
| 처리완료 | 건수 | 가능 |
| 이슈없음 | 건수 | 가능 |
| 처리율 | % | 가능 |
| 평균 처리 기간 | n.n일 | 가능 |
| 기한 초과 | 건수 | 가능 |
| 기한 내 처리율 | % | 가능 |

- 집계 기준 드롭다운(기간별 / 이슈 유형별 / 담당 관리자별)의 기본값은 기간별이다.
- 기간별을 고르면 집계 단위 드롭다운(일 / 주 / 월 / 연)을 함께 표시한다. 기본값은 일이다. 주는 월요일~일요일, 월은 1일~말일, 연은 1월 1일~12월 31일을 한 단위로 본다.
- 주·월·연 단위의 첫 행과 마지막 행은 조회 기간에 포함된 날짜만 집계한다.
- 표 맨 위에 '합계' 행을 고정하고 요약 카드와 같은 값을 표시한다. 정렬·합계 행 처리 방식은 통계 표와 같다.

### 상태별 표시

| 상태 | 표시 |
| --- | --- |
| 검색 중 | 요약 카드·통계 표·이슈 콜 처리 현황 로딩 표시, [검색] 비활성 |
| 조건에 해당하는 콜 없음 | 요약 카드 건수 0건, 평균 시간 '-'. 통계 표에 '선택한 조건에 해당하는 콜이 없습니다.' |
| 조회 실패 | 통계를 불러오지 못했습니다. 다시 시도해 주세요. + [다시 시도] |

### 콜 통계 정책

- 관리자 화면 메뉴다. 접근 권한과 조회 범위는 역할 관리의 메뉴 권한과 데이터 조회 범위를 따른다.
- 콜 통계와 상담이력은 같은 콜 데이터와 같은 재인입·이슈·묵음 판정 결과를 사용한다.
- 이슈 콜 처리 현황은 이슈 콜 목록의 상태·이슈 기한·이슈 유형·담당 관리자·처리 완료일을 그대로 사용한다.
- 재인입 콜·이슈 콜 여부는 콜 분석 시점의 결과를 기준으로 한다. 이후 키워드 관리에서 키워드를 바꿔도 이미 분석된 콜의 판정 결과와 통계는 바뀌지 않는다.

## 실시간 상태 모니터링 (리더어드바이저)

리더어드바이저의 기존 실시간 상태 모니터링 화면에 이슈 콜 영역을 추가한다. 기존 화면 구성과 웹소켓 연결 오류 화면은 프로토타입과 Figma(L_리더_실시간_상태모니터링_웹소켓_error_02)를 따르며, 이 문서에는 추가하는 이슈 콜 영역만 적는다.

### 추가 영역

| 영역 | 구성 |
| --- | --- |
| 이슈 콜 인입 추이 | 오늘 시간대별 이슈 콜 인입 건수 그래프 + 요약(오늘 인입 n건, 최근 1시간 n건, 전일 같은 시각까지 대비 증감) |
| 처리 단계별 상태 | 미처리 / 검토필요 / 처리완료 / 이슈없음 건수 카드 + 상태별 비율 누적 막대 + 기한 초과 카드 |

### 이슈 콜 인입 추이

| 항목 | 내용 |
| --- | --- |
| 인입 기준 | 이슈 콜 목록에 등록된 시점 (BE가 이슈 키워드를 태깅한 시점) |
| 그래프 | 막대 그래프. 가로축은 오늘 00시부터 현재 시각까지 1시간 단위(확인 필요), 세로축은 이슈 콜 건수. 전일 같은 시간대 건수를 선 그래프로 겹쳐 표시 |
| 요약 | 오늘 인입 n건 / 최근 1시간 n건 / 전일 같은 시각까지 대비 증감(+n건 또는 −n건) |
| 마우스 오버 | 해당 시간대(HH:00~HH:59)의 오늘 건수와 전일 건수 툴팁 |
| 갱신 | 이슈 콜이 등록될 때마다 실시간으로 반영 |

### 처리 단계별 상태

| 항목 | 내용 |
| --- | --- |
| 상태별 카드 | 미처리 / 검토필요 / 처리완료 / 이슈없음 건수. 상태 이름과 색상은 이슈 콜 목록의 상태 배지와 같음 |
| 누적 막대 | 4개 상태의 비율(%)을 한 줄 막대로 표시. 마우스 오버 시 상태별 건수·비율 툴팁 |
| 기한 초과 카드 | 등록일과 관계없이 처리 전('미처리'·'검토필요')이면서 기한일이 지난 이슈 콜 전체 건수 |
| 집계 대상 | 상태별 카드와 누적 막대는 오늘 등록된 이슈 콜 (확인 필요). 4개 카드 합계는 오늘 인입 건수와 같다 |
| 클릭 | 상태별 카드를 누르면 기간 '오늘'과 해당 상태로 필터를 건 이슈 콜 목록으로 이동. 기한 초과 카드를 누르면 '기한 초과만 보기'를 켠 이슈 콜 목록으로 이동 |
| 갱신 | 이슈 콜 등록, 상태 변경, 기한 지정 때마다 실시간으로 반영 |

### 실시간 상태 모니터링 상태별 표시

| 상태 | 표시 |
| --- | --- |
| 오늘 등록된 이슈 콜 없음 | 그래프 영역에 '오늘 등록된 이슈 콜이 없습니다.' 표시, 상태별 카드 0건 |
| 실시간 연결 끊김 | 기존 웹소켓 오류 표시를 따른다. 이슈 콜 영역에는 마지막 갱신 일시(yyyy.mm.dd HH:mm:ss)를 표시 |
| 조회 실패 | 이슈 콜 현황을 불러오지 못했습니다. 다시 시도해 주세요. + [다시 시도] |

### 실시간 상태 모니터링 정책

- 로그인 사용자 역할의 데이터 조회 범위에 속한 이슈 콜만 집계한다.
- 이슈 콜 영역은 이슈 콜 목록 조회 권한이 있는 역할에만 표시한다.
- 수치는 이슈 콜 목록, 콜 통계 '이슈 콜 처리 현황'과 같은 데이터와 같은 상태·기한 정의를 쓴다.

### 역할 관리 정책

- 기본 역할은 삭제할 수 없다. 이름을 바꿀 수 있는지는 확인 필요.
- 관리자 역할의 '역할 관리' 조회·편집 권한은 해제할 수 없다. 역할을 관리할 사용자가 없어지는 것을 막기 위해서다.
- 바뀐 권한을 적용하는 시점(즉시 또는 다음 로그인)은 확인 필요.
- 역할 등록·수정·삭제는 변경 전·후 권한과 함께 감사로그에 기록한다.

### 감사로그 정책

- 감사로그는 관리자를 포함해 누구도 수정하거나 삭제할 수 없다.
- 로그에는 작업 대상의 식별값만 남기고, 전사 텍스트 같은 상담 내용은 남기지 않는다.
- 감사로그 조회도 감사로그에 기록한다. (확인 필요)
- 보관 기간은 확인 필요.

## 확인 필요 사항

### 공통 LNB

1. 업무 메뉴의 순서와 그룹 구성
2. 알림 메뉴 포함 여부 (AutoQA 프로토타입의 LNB 하단에는 알림과 공지사항이 있음)
3. 사용자 관리·역할 관리·감사로그를 상담어드바이저와 리더어드바이저가 함께 쓰는지(사용자·역할 공유), 포털마다 따로 두는지

### 상담이력

1. 역할별 조회 범위: 상담사(상담어드바이저)는 본인 콜만 조회하는지, 이 경우 센터·팀·사번 필터를 노출할지 / 리더(리더어드바이저)의 조회 범위(소속 팀 또는 센터)
2. 기간 필터 기본값과 최대 조회 기간
3. 사번 필터의 일치 방식(완전 일치·부분 일치)과 다중 입력 허용 여부
4. 키워드 검색의 일치 방식(완전 일치·부분 일치)과 여러 키워드 동시 입력 허용 여부
5. 입력한 키워드와 일치하는 감지 키워드가 없을 때 처리 (결과 없음 표시 또는 전사 텍스트 전체 검색)
6. 상담유형(대분류 > 중분류 > 소분류 > 세분류 단계별 선택)·I/B·O/B 필터 추가 여부
7. 키워드 컬럼 정렬 기준 (제안: 정렬 제외)
8. 페이지 크기 기본값 (제안: 20)
9. 일시 기준: 통화 시작 시점 또는 종료 시점
10. 묵음시간 산정 기준: 몇 초 이상 무음이면 묵음 구간으로 볼지
11. 재인입 판단 기준: 동일 고객의 재통화를 몇 시간 이내로 볼지
12. 이상 지표 항목 구성과 지표별 기준값(이슈 키워드 감지 기준 포함)
13. 상담유형 분류: 단계별 분류값을 누가 어디서 관리하는지(관리 화면 필요 여부), 하위 단계까지 분류하지 못한 콜의 표시 방식, 분류 체계가 바뀔 때 이미 분석된 콜을 다시 분류할지, 복수 분류 표시 여부
14. 분석이 끝나지 않은 콜의 목록 노출 여부와 표시 방식
15. 녹취 다운로드 제공 여부 (녹취 재생 이력은 감사로그에 기록)
16. 목록에서 선택한 키워드 유형을 상세 기본값으로 이어받을지 여부

### 이슈 콜

1. 이슈 기한을 바꿀 때 기한일을 등록일이 속한 기간 기준으로 다시 계산할지(현재 문서), 바꾼 날이 속한 기간 기준으로 계산할지
2. 기간 끝 무렵에 등록된 이슈 콜 처리: 그대로 둘지(현재 문서), 등록 시각이나 요일에 따라 다음 기간으로 넘길지 (예: 일요일 등록 '주' 기한은 당일 마감)
3. 기본 이슈 기한 값(제안: 주)과, 이슈 유형별로 기본 기한을 따로 둘지
4. 기한 임박(예: 기한일 당일) 표시나 알림이 필요한지
5. 이슈 유형 지정 방식: 담당 관리자가 직접 지정(현재 문서) 또는 이슈 키워드에 따라 자동 지정
6. 담당 관리자 자동 지정 여부 (예: 이슈 유형의 담당자가 1명이면 자동 지정)
7. 상담사 공개 범위 기본값 (제안: 본인)
8. 공개 범위가 '센터'·'전체'일 때 다른 상담사 콜의 상담이력 상세(전사 텍스트·녹취 재생)와 처리 내용·처리 내역까지 보여줄지 (제안: 콜 기본 정보와 이슈 처리 영역만 보여주고 전사 텍스트·녹취는 숨김)
9. 상태 필터 기본값 (제안: 미처리·검토필요)
10. '이슈없음'도 처리 완료일을 기록할지, '처리완료' 뒤에 상태를 다시 바꿀 수 있는지
11. 처리 내용 필수 조건 (제안: '처리완료'·'이슈없음'으로 바꿀 때 필수)
12. 담당 관리자 지정·상태 변경 시 담당 관리자나 상담사에게 알림을 보낼지
13. 이슈 콜 목록 엑셀 다운로드 제공 여부
14. 콜 통계 '이슈 콜' 건수에서 '이슈없음' 콜을 뺄지 (제안: 감지 건수는 그대로 두고 '확정 이슈 콜'을 따로 표시)
15. 처리 현황의 상태 기준: 조회 시점의 현재 상태 또는 기간이 끝난 시점의 상태
16. 이슈 콜 설정 편집 권한의 기본 역할 (제안: 리더·관리자)

### 실시간 상태 모니터링

1. 인입 기준 시점: 이슈 콜 등록 시점(현재 문서) 또는 통화 일시. 통화 중에 실시간으로 이슈 키워드를 감지하는지
2. 그래프 시간 단위(제안: 1시간)와 비교 기준(전일 또는 전주 같은 요일)
3. 처리 단계별 상태의 집계 대상: 오늘 등록된 이슈 콜(현재 문서) 또는 처리 전인 이슈 콜 전체
4. 이슈 콜 목록 기간 필터(통화 일시 기준)와 기준을 맞출지. 기준이 다르면 자정 전후 콜은 카드 건수와 목록 건수가 다를 수 있음
5. 상담어드바이저에도 이슈 콜 현황을 보여줄지

### 키워드 태그

1. FE 태그 뱃지 표시 여부 (제안: 이슈 키워드에만 '이슈' 뱃지를 붙이고 상담 키워드는 뱃지 없이 표시. 적용 위치는 상담이력 상세의 콜 기본 정보·추출 키워드·전사 텍스트 하이라이트와 상담이력 목록의 키워드 컬럼)
2. 키워드 태그와 키워드 유형의 관계: 한 키워드가 유형과 태그를 함께 가지는지(예: 상품 유형이면서 이슈 키워드), 이슈 키워드는 키워드 관리에서 등록하지 않고 BE가 추출하는지
3. 상담이력 목록에서 이슈 키워드 태그로 필터링하는 기능 제공 여부

### 키워드 관리

1. 제외 키워드의 용도 (무엇에서 제외하는 키워드인지)
2. 키워드 관리 편집 권한을 상품 탭과 키워드 탭으로 나눌지 (상품 탭 변경은 기간계로 전송되므로)
3. 같은 키워드를 서로 다른 유형에 등록할 수 있는지 (상품 연관 키워드와 키워드 탭 키워드 사이 포함)
4. 최대값: 키워드·설명·유형명 글자 수, 추가할 수 있는 유형 개수
5. 연관 상담유형의 필수 여부, 선택 단계(세분류까지 선택해야 하는지), 용도(표시용 정보인지, 키워드 감지 조건에 쓰는지), 엑셀 양식의 입력 형식(분류 경로 또는 분류 코드)
6. 추가한 유형의 이름 변경·삭제 제공 여부와, 유형을 삭제할 때 그 유형에 등록된 키워드 처리
7. 추가한 유형의 표시 색상 (상담이력 목록·상세에서 유형별 색상으로 구분할 때)
8. 엑셀 일괄 등록: 오류 행 처리 방식(제안: 오류 행만 빼고 등록, 대안: 오류가 하나라도 있으면 전체 미등록), 최대 건수와 파일 크기
9. 실시간대화 검색어 기능과 등록 키워드·키워드 유형의 연계 여부

### 상품 탭 (기간계 전송)

1. 기간계 팀의 상품 등록·수정·삭제 쓰기 API 제공 여부와 개발 일정, 상품 담당 부서의 합의
2. 전송 방식: 저장할 때 바로 보내는지(실시간), 모아서 보내는지(배치)
3. 저장 방식: 포털에 먼저 저장한 뒤 보내는 방식(현재 문서) 또는 기간계 반영에 성공했을 때만 저장하는 방식
4. 기간계에서 상품 정보를 직접 수정하지 못하게 막는 방법과, 기간계 상품 화면을 쓰던 부서의 업무 절차 변경
5. 초기 이관: 기존 기간계 상품을 포털로 옮기는 방식과 시점, 대상 범위(전체 상품 또는 관리할 상품만)
6. 상품 코드 형식, 필수값 등 기간계 입력 규칙
7. 기간계가 상품 삭제를 허용하는지(예: 사용 중인 상품). 허용하지 않으면 사용상태 '미사용' 전환으로 대신할지
8. 상품 등록·수정·삭제에 승인 절차가 필요한지
9. 사용상태 값(사용·미사용 외 값이 있는지)과, 미사용 상품의 연관 키워드를 감지에 계속 쓸지
10. 기간계 반영 전(반영 대기·반영 실패) 상품의 연관 키워드를 감지에 쓸지
11. 연관 키워드의 활용처: 상담이력에서 '상품' 유형으로 검색할 때 상품명과 함께 검색 대상에 넣을지, 감지된 연관 키워드를 상품명으로 묶어 표시할지
12. 같은 연관 키워드를 여러 상품에 등록할 수 있는지
13. 상품당 연관 키워드 최대 개수와 글자 수, 상품·연관 키워드 엑셀 일괄 등록 제공 여부

### 콜 통계

1. 관리자 역할의 기본 데이터 조회 범위 (전체 센터 또는 담당 센터)
2. 이슈 콜 정의: 이슈 키워드가 1건 이상 태깅된 콜로 볼지
3. 평균 통화시간·평균 묵음시간의 분모: 분석이 끝나지 않아 묵음시간이 없는 콜을 제외할지
4. 기간 필터 기본값(제안: 최근 7일)과 최대 조회 기간, 집계 단위 기본값(제안: 일자별)
5. 데이터 갱신 주기(실시간 또는 일 단위 배치)와 집계 기준 일시 표시 방식
6. 사번·상담사·I/B·O/B·상담유형 필터와 상담사별·상담유형 단계별 집계 단위 추가 여부
7. 재인입률·이슈 콜 비율(건수 ÷ 전체 콜) 표시 여부
8. 요약 카드나 표의 건수를 클릭하면 같은 조건의 상담이력 목록으로 이동할지
9. 엑셀 다운로드 제공 여부

### 공지사항

1. 게시 대상 구분(전체 / 상담사 / 리더) 필요 여부
2. 첨부파일 제공 여부와 파일 형식·개수·크기
3. '중요' 공지 상단 고정 여부와 고정 개수
4. 게시 기간(시작일~종료일) 설정 여부
5. 새 공지를 LNB 배지 등으로 알릴지

### 사용자 관리

1. 인증 방식: 사내 SSO·AD 연동인지, 포털 자체 계정인지. SSO라면 사용자 등록을 인사 정보 연동으로 대신할지
2. 사용자 한 명에게 역할을 여러 개 지정할 수 있는지
3. 계정 잠금 기준(로그인 실패 횟수)과 비밀번호 초기화 방식 (자체 계정일 때)
4. 퇴사·휴직자를 자동으로 '미사용' 처리할지
5. 사용자 삭제 대신 '미사용' 처리 (제안)

### 역할 관리

1. 기본 역할 구성(상담사·리더·관리자 외)과 역할별 기본 메뉴 권한·데이터 조회 범위
2. 기능 단위 권한 분리 여부 (예: 녹취 재생, 상품 기간계 전송, 엑셀 업로드)
3. 바뀐 권한을 적용하는 시점 (즉시 또는 다음 로그인)
4. 데이터 조회 범위에 '지정한 센터·팀' 선택지가 필요한지
5. 기본 역할의 이름 변경 허용 여부

### 감사로그

1. 기록 대상 작업 범위 (조회 기록 포함 여부)
2. 보관 기간 (관련 규정 기준)
3. 감사로그 조회 권한 (관리자 전체 또는 별도 감사 역할)
4. 엑셀 다운로드 제공 여부 (제공하면 다운로드도 감사로그에 기록)
5. 접속 IP 외 기록 항목 (예: 단말 정보)
6. 기간 필터 기본값과 최대 조회 기간
